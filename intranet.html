Mit GitHub verbinden

Zum Speichern von Änderungen wird ein persönlicher GitHub-Token mit Schreibrechten auf dieses Repository benötigt (Settings → Developer settings → Personal access tokens → Fine-grained, Berechtigung „Contents: Read and write" auf das Repo sanova-umwelttechnik-website). Der Token wird ausschließlich lokal in deinem Browser gespeichert und nie in den Code übernommen.
